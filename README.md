# 全臺PM2.5空氣品質長期趨勢分析

以環境部「環境資料開放平臺」公開的全臺PM2.5日均值資料為對象，完整走過資料探索、資料品質檢查、長期趨勢與季節性視覺化、縣市／假日平日／氣象因子關係分析，到預測模型建立的全流程。過程中發現原始資料存在重複列問題並加以修正，是「政府開放資料應用案例」系列的第二個作品。

線上報告頁面：開啟本repo的GitHub Pages連結即可看到（`index.html`）。

## 資料集

- 來源：環境部[環境資料開放平臺](https://data.moenv.gov.tw/)「PM2.5日均值(每日提供)」資料集（AQX_P_322），以及中央氣象署[CODiS氣候觀測資料查詢服務](https://codis.cwa.gov.tw/)。
- 範圍：全臺性，按月份批次下載，涵蓋2022年1月～2026年8月共56個月份。另外向CODiS下載臺北測站（466920）2022～2026年「全項逐月年報表」，取得風速、降水量資料。
- 資料集本身不包含在這個repo裡，需要自行從上述兩個平臺下載對應的月份／測站資料。

## 專案流程與腳本

腳本依執行順序編號，直接放在repo根目錄，執行前請把對應腳本跟下載到的56個月份PM2.5 CSV（以及氣象CSV，執行03b、04時需要）放在同一個資料夾：

1. `01_data_exploration.py` — 確認56個月份資料能否正常合併讀取、欄位、日期範圍、測站數，並檢查同一測站同一天是否有重複列。
2. `02_eda_charts.py` — 畫出「原始筆數vs去重複後筆數」對比圖、全臺月平均濃度長期趨勢、各月份平均濃度季節規律共3張圖表。
3. `03_relationship_analysis.py` — 縣市間比較、假日vs平日比較，共2張圖表。
4. `03b_weather_correlation.py` — 額外整合CODiS臺北測站氣象資料，分析風速、降水量與PM2.5的相關性，共2張圖表。
5. `04_prediction_model.py` — 線性迴歸與Random Forest比較，用縣市、年份、月份、星期幾預測PM2.5濃度，含特徵重要性分析。

## 分析結果

### 資料品質：重複列問題

合併56個月份、共214,478筆原始資料後，發現同一測站、同一天出現超過一筆紀錄的情形，尤其在2024年後明顯增加，最誇張一筆同一測站同一天重複達5次。原本假設是「監測站數量增加」造成筆數暴增，但畫出「每月不重複測站數」後發現測站數僅78→80站、幾乎沒有成長，才確認是原始資料本身存在82,679筆重複列，去重複後剩130,832筆有效資料。

### 長期趨勢與季節性

- 全臺PM2.5月平均濃度呈現非常規律的季節循環：冬季（11月～4月）偏高、夏季（6～8月）偏低，1月平均18.9 μg/m³ 對比 6月平均約7~8 μg/m³，振幅超過2.5倍。
- 各縣市差異明顯：高雄市17.8 μg/m³最高，臺東縣6.0 μg/m³最低，西南部與離島普遍偏高、東部偏低。
- 假日與平日幾乎無差異（13.61 vs 13.47 μg/m³），代表PM2.5主要受區域性背景污染主導，而非交通尖峰時段等短期人為因素。

### 氣象因子關聯分析（臺北測站，n=56個月）

| 關係 | 相關係數 | 結論 |
|---|---|---|
| 風速 vs PM2.5 | r = 0.343 | 正相關，但屬「季節」同時影響兩者的混淆變數效應，非風速直接推高PM2.5 |
| 降水量 vs PM2.5 | r = -0.579 | 中度負相關，符合降雨沖刷空氣污染物的物理直覺 |

### 預測模型（訓練集24,000筆、測試集6,000筆，從13萬筆中隨機抽樣3萬筆建模）

| 模型 | R平方 | MAE | RMSE |
|---|---|---|---|
| 線性迴歸 | 0.3681 | 5.219 μg/m³ | 6.796 μg/m³ |
| **Random Forest** | **0.3972** | **4.978 μg/m³** | **6.638 μg/m³** |

特徵重要性前3名為高雄市（縣市別）、6月、8月（季節月份），與縣市及季節性分析結果互相驗證。R平方約0.37~0.40，較房價案例略低，反映PM2.5受天氣、境外傳輸等本次未納入的外部因素影響較大。

## 為什麼建模時沒有納入風速、降水量？

Stage 3b的氣象關聯分析用的是「全臺月平均PM2.5」對「臺北單一測站的月資料」，是月為單位、全國只有一組數字。但預測模型是用「每個測站、每一天」的原始紀錄，如果每一筆都套用同一個臺北測站的月平均風速/雨量，等於81個測站在同一個月都套用一模一樣的天氣數字，會嚴重扭曲模型、也不合理（雲林的天氣不會跟臺北一樣）。要做到「每個測站」等級的天氣特徵，需要另外抓每個測站附近氣象站的逐日資料，工程量很大，所以這次模型主動排除風速、降水量，只用縣市、年份、月份、星期幾這些顆粒度一致的特徵，並在報告裡誠實說明這個限制。
